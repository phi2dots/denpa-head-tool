# 電波人間 頭の形 出生ルート検索ツール

`new 電波人間のRPG FREE` の頭の形について、標準出生ルールや特徴を調べるためのWebツールです。

公開ページ:

https://phi2dots.github.io/denpa-head-tool/

## できること

- 頭の形の名前、タイプ、補正、耐性、特殊効果による検索
- 頭の形ごとのステータス補正、属性耐性、状態異常耐性、特殊効果の確認
- 標準出生ルールの一覧確認
- 選択した頭の形を中心にした出生ルートの表示
- 出生ルート上での進化元、進化先の展開
- 出生ルートの一部非表示やノード位置の調整

## 使い方

1. 公開ページを開きます。
2. 左側または上部の検索・フィルタで頭の形を探します。
3. 一覧から頭の形を選択します。
4. 出生ルート上の `+` から進化元や進化先を展開します。
5. 詳細パネルで選択中の頭の形の特徴を確認します。

## データについて

このツールでは、標準出生ルールのみを扱います。

実際のゲーム内では、配合回数、親の順番、個体ごとの条件などで結果が変わる可能性があります。現時点では、ユーザーごとの所持キャラクター管理や個別の出生記録管理には対応していません。

出生確率は未表示です。

## 注意

このツールは非公式の補助ツールです。ゲーム本体、公式情報、各種権利者とは関係ありません。

掲載データには誤りや不足が含まれる可能性があります。利用時は参考情報として扱ってください。
